# MeglaNote

A simple Mac notes app for Markdown, in the Zettelkasten style: lots of small notes, linked together.

Every note is a plain `.md` file in a folder you choose, such as iCloud Drive, named after its title. There's no database and no lock-in. The files open in any other Markdown editor, and the MeglaNote iPhone companion app edits the same folder.

## What it does

- **Write in Markdown** with an Edit / Preview toggle, tables, and column layouts.
- **Link notes** with `[[double brackets]]`, which autocomplete as you type. Each note shows the other notes that link back to it.
- **Organise** with nested folders, tags, colour flags and pinned notes, plus search.
- **Collapsible headings**, so you can fold long notes down. A `---` line acts as a section break.
- **Images and attachments.** Paste or drag in images, then resize them in Preview. Drop in PDFs and other files to get a preview thumbnail that opens the original when clicked.
- **Templates and meeting notes**, including person notes (a note in a `People` folder, or tagged `person`) that collect every meeting that person was in.
- **Home page** with an overview of your notes.
- **Stays in sync.** If a note changes on the phone or another Mac, MeglaNote picks up the change. If you were editing that note at the same time, it asks which version to keep.
- **Trash.** Deleted notes wait 14 days before they're cleared. Any images or attachments that no other note uses are cleared with them. **File → Clean Up Unused Files…** tidies up any leftovers.
- **Web clipper.** Save a highlight and its page link from the browser straight into a new note.
- **Themes:** Light, Dark, Pastel and Kawaii.
- **Updates itself** when a new version is published.

## Installing

Open the `.dmg` from the latest release and drag MeglaNote into Applications.
